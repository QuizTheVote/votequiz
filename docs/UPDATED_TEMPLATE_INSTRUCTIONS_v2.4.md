## 📋 GETTING STARTED

### 1. MAKE YOUR COPY
• File → Make a Copy
• Rename to: "[Your Organization] Election Quiz 2025"
• This creates your customizable version

### 2. CUSTOMIZE YOUR QUIZ
• Go to "Quiz_Data" tab
• Review the pre-loaded Social Value Orientation questions
• Replace sample candidates with your local candidates
• Enable/disable questions using the "Active" column (TRUE/FALSE)
• Modify candidate positions based on their public statements
• Use Essential questions (5) for quick quiz, Additional (5 more) for comprehensive

### 3. CUSTOMIZE CANDIDATE INFORMATION ✨ NEW
• Go to "Candidates" tab
• **Column F (link_url):** Add candidate website or your coverage URL
• **Column G (link_text):** Customize button text for each candidate:
  - "Read Our Coverage" - Links to your candidate profiles
  - "Campaign Website" - Links to official campaign sites
  - "View Profile" - For detailed candidate information
  - "Visit Website" - Default if left blank
• **Photo URLs:** Paste Google Drive sharing URLs directly (auto-converts to direct image URLs)

### 4. HANDLE NON-PARTICIPATING CANDIDATES ✨ NEW
• **Partial Responses:** Candidates answering <50% of questions appear in "Additional Candidates" section
• **Non-Responses:** Candidates answering 0% appear with "Did not respond to survey"
• **Professional Display:** Clear messaging without penalizing partial participation
• **Scoring Impact:** Only answered questions count toward match percentages

### 5. COLLECT CANDIDATE DATA
• Use "🗳️ Quiz Tools" → "📝 Generate Candidate Survey"
• Send the created Google Form to all candidates
• Responses automatically populate your candidate columns
• Review and verify candidate answers before publishing

### 6. PUBLISH & DEPLOY
• 🔓 **FIRST:** Click "Share" → "Anyone with the link" → "Viewer" → "Done"
• 📋 Click the "Quiz_Data" tab at the bottom of your sheet
• 📤 File → Share → Publish to Web → Quiz_Data sheet → CSV → Publish
• 🔗 **IMPORTANT:** Copy the URL from your browser's address bar
• 🔗 Use the URL that looks like: `docs.google.com/spreadsheets/d/YOUR_ID/edit`
• ❌ NOT the published URL from the dialog box
• Visit: https://www.quizthevote.com/build-your-quiz/ 
• Paste your browser URL to generate embed code

## 🎯 TROUBLESHOOTING

### **Common Issues & Solutions:**

**Images Not Displaying:**
• Use Google Drive sharing URLs or direct image links
• Ensure images are publicly accessible
• Check that URLs don't contain spaces or special characters

**Blank Questions Appearing:**
• Verify all enabled questions (Active = TRUE) have question text
• Check for empty rows in Quiz_Data sheet
• Use Template Health Check to identify issues

**Candidate Buttons Not Working:**
• Verify link_url column contains valid URLs
• Check that URLs include `https://` prefix
• Test links manually before publishing

**Match Percentages Seem Wrong:**
• Only answered questions count toward percentages
• Candidates with <50% response rate appear in Additional Candidates
• Use Template Health Check to verify data completeness
