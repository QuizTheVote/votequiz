CREATE ENGAGING CANDIDATE MATCHING QUIZZES FOR YOUR AUDIENCE

📋 GETTING STARTED:

1. MAKE YOUR COPY
   • File → Make a Copy
   • Rename to: "[Your Organization] Election Quiz 2024"
   • This creates your customizable version

2. CUSTOMIZE YOUR QUIZ
   • Go to "Quiz_Data" tab
   • Review the pre-loaded Social Value Orientation questions
   • Replace sample candidates with your local candidates
   • Enable/disable questions using the "Active" column (TRUE/FALSE)
   • Modify candidate positions based on their public statements
   • Use Essential questions (5) for quick quiz, Additional (5 more) for comprehensive

3. COLLECT CANDIDATE DATA (NEW!)
   • Use "🗳️ Quiz Tools" → "📝 Generate Candidate Survey"
   • Send the created Google Form to all candidates
   • Responses automatically populate your candidate columns
   • Review and verify candidate answers before publishing

4. PUBLISH & DEPLOY
   • 🔓 FIRST: Click "Share" → "Anyone with the link" → "Viewer" → "Done"
   • 📋 Click the "Quiz_Data" tab at the bottom of your sheet
   • 📤 File → Share → Publish to Web → Quiz_Data sheet → CSV → Publish
   • 🔗 IMPORTANT: Copy the URL from your browser's address bar
   • Use the URL that looks like: docs.google.com/spreadsheets/d/YOUR_ID/edit
   • ❌ NOT the published URL from the dialog box
   • Visit: https://evanwyloge.github.io/votequiz/newsroom.html
   • Paste your browser URL to generate embed code
